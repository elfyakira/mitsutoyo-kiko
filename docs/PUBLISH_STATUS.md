## CPI の注意点

- CPI 標準 DNS は **自分で編集できない**。有料オプション「DNSサーバーレンタル」契約のうえ CPI スタッフに変更を依頼する
  - 初年度 19,800 円（設定費 5,500 + 年額 14,300）、2 年目以降 年額 14,300 円、変更作業 1 回 5,500 円（税込、2026-10 時点）
  - 申請: マイページ → ご契約一覧 → DNSサーバーレンタル詳細 → レコード追加・変更申請
- ログイン画面は 3 種類で ID が別
  - マイページ（契約・DNS 申請）: https://login.cpi.ad.jp/login.php
  - コントロールパネル: https://cp.secure.ne.jp/login
  - ユーザーポータル（旧プラン）: https://login.secure.ne.jp/cp_login.php
- 受領済みのホスト名 / ユーザー名 / パスワードは **FTP 情報** で、DNS 変更には使えない
